## Возможности
* **Быстрая вставка:** Вставляет строку `Hello, World!` в позицию курсора в активном редакторе.
* **Интеграция в меню:** Плагин добавляет новый пункт **"Insert Hello, World!"** в главное меню `Tools` (Инструменты).
* **Контекстная доступность:** Пункт меню активен только тогда, когда открыт какой-либо файл в редакторе (если фокус находится в других окнах, действие скрыто или неактивно).
* **Безопасное редактирование:** Вставка текста происходит через механизм `WriteCommandAction`, что гарантирует корректную работу с системой отмены действий (Undo/Redo).

## Как использовать
1. Откройте любой файл в CLion.
2. Установите курсор в то место, куда вы хотите вставить текст.
3. В верхнем меню выберите **Tools** -> **Insert Hello, World!**.
4. В указанное место будет добавлена строка `Hello, World!`.
5. При необходимости отмените действие с помощью `Ctrl+Z`.
